# ConCopy - Direttive Progetto

Clipboard manager nativo per macOS 14+ ispirato a Copy 'Em (Swift 5.9+, AppKit, SwiftUI).

## Architettura a 3 Target

1. `ConCopyCore`
   - Logica di dominio, monitoraggio `NSPasteboard`.
   - Storage SQLite con `GRDB.swift` + FTS5.
   - Salvataggio blob su disco tramite hash SHA-256.
   - Iniezione paste con `CGEvent`.
   - Nessuna dipendenza da viste SwiftUI.

2. `ConCopyUI`
   - Gestione finestre AppKit (`NSPanel`).
   - Viste SwiftUI ospitate tramite `NSHostingView`.
   - Scorciatoie globali con `KeyboardShortcuts`.
   - Dipende da `ConCopyCore`.

3. `ConCopyApp`
   - Entry point eseguibile macOS configurato come menubar app (`LSUIElement = true`).
   - Gestione ciclo di vita, `NSStatusItem`, permessi Accessibility.
   - Dipende da `ConCopyCore` e `ConCopyUI`.

## Regole Critiche di Sistema

- **No Focus Stealing**:
  - Finestra principale eredita da `NSPanel`.
  - StyleMask: `[.titled, .nonactivatingPanel, .fullSizeContentView, .resizable]`.
  - `isFloatingPanel = true`, `level = .floating`, `becomesKeyOnlyIfNeeded = true`.
  - L'app attiva non deve mai perdere il focus durante visualizzazione o iniezione.

- **Filtro Privacy**:
  - Scartare sempre elementi pasteboard contenenti:
    - `org.nspasteboard.TransientType`
    - `org.nspasteboard.ConcealedType`
    - `org.nspasteboard.AutoGeneratedType`
    - `com.agilebits.onepassword`

- **Qualità del Codice**:
  - Nessun force unwrap (`!`) o `fatalError` in produzione.
  - Swift Concurrency (`async/await`, `actor`, `@MainActor` dove appropriato).

## Comandi di Verifica

- Build: `swift build`
- Test: `swift test`
