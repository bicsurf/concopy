# Contributing to ConCopy

Thank you for your interest in contributing to ConCopy! We welcome community contributions, bug reports, and suggestions.

---

## Getting Started

1. **Fork the Repository**: Create a personal fork of ConCopy on GitHub.
2. **Branch from `main`**: Create a descriptive feature or fix branch:
   ```bash
   git checkout -b feat/your-feature-name
   # or
   git checkout -b fix/your-bug-fix
   ```
3. **Verify Build & Tests**:
   Before submitting your changes, ensure that the codebase builds cleanly without warnings and that all tests pass:
   ```bash
   swift build
   swift build -c release
   swift test
   ```
4. **Submit a Pull Request**: Open a pull request against the `main` branch with a clear description of the problem solved or feature added.
